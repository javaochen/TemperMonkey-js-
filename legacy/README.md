# 已归档脚本

这里存放被新版本取代的脚本，仅用于查阅历史实现，**请勿安装**。

| 文件 | 说明 |
|---|---|
| `toc-v3.0.0.user.js.txt` | 「网页悬浮目录」v3，已由根目录的 [`toc.user.js`](../toc.user.js)（v4）取代。 |

## 为什么改成 `.txt`

归档文件被重命名为 `.txt`，浏览器打开时只会显示源码文本，避免误触发 Tampermonkey 的安装页。如需查看或对比实现，直接用编辑器打开即可；需要临时安装测试时，请复制为 `.user.js` 再装。

## 版本关系

v4 是 v3 的超集：新增了按钮拖拽、点选定位、位置记忆与复位、面板跟随定位、移动端适配。v3 没有任何 v4 缺少的功能。两者使用相同的 `gm-toc-root` 节点 id，同时安装时只有先加载的那个会生效。
